1. 用精确二项分布枚举固定样本量接收方案，并展示备择次品率未指定时样本量不唯一；
2. 逐格重算 P03 表 4 中“不拆解”对应的 8×6 个利润值；
3. 用 Beta-Binomial 后验抽样演示次品率不确定性如何传递到策略选择。
