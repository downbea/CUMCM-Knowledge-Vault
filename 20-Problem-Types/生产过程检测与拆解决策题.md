# 生产过程检测与拆解决策题

## 题型识别

典型题面同时包含供应商次品率验收、零件/半成品/成品检测、装配缺陷、售后退换、拆解回收以及次品率估计误差。子问通常形成：

```text
抽样验收 → 单级检测/拆解决策 → 多级装配网络 → 参数不确定性下重新决策
```

## 推荐建模路线

1. 用 [[精确二项验收抽样]] 明确 (p_0,p_1,\alpha,\beta) 和整数判定规则；
2. 对两零件小系统枚举全部策略，建立数量/概率守恒和单件最终合格品期望利润；
3. 把多级装配表示为 [[多阶段检测拆解与退换决策]] 状态网络，以 [[动态规划]]、整数网络流或离散事件仿真求解；
4. 用 [[Beta-二项质量不确定性传播]] 把真实 (n,k) 传入策略评价，报告策略频率、利润区间和后悔值；
5. 元启发式只在状态或策略空间确实较大时使用，并以枚举/DP/MILP为基线。

## 数据要求

需要BOM拓扑、各节点抽样量和次品数、检测灵敏度/特异度、采购/检测/装配/拆解/退换成本、售价、库存/产能、回收规则与终止条件。题设次品率与抽样估计值要分开保存。

## 高风险错误

- 未指定 (p_1) 却声称得到唯一最小样本量；
- 把左尾/右尾统计结论翻译成相反的接收或拒收动作；
- 用库存数量连乘表示产量；
- 检测成品后把销售收入设为零；
- 反馈回路只有流程图，没有状态转移和吸收条件；
- 用单次随机利润驱动GA/SA/ACO；
- 把区间端点同策略等同于高概率稳健。

## 验证指标

抽样层报告OC曲线与两类风险；生产层报告数量守恒、单件利润、策略最优差距和运行时间；仿真层报告均值、标准误/区间与随机种子；不确定性层报告策略选择概率、下分位数、后悔值和信息价值。
